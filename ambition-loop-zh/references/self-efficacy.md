# 自我效能笔记：为什么信念和难目标对 agent 同样重要

原文结尾落在一个心理学观点上。人被"自己以为什么是可能的"所限制，而且往往只在很窄的学科里相信自己。自我效能（Bandura）就是对自身能力的信念，它能预测一个人最终能做成多少事。原文认为这种信念可以被"破解"。

| 杠杆 | 人类证据（来自原文） | 在 agent 身上的用法 |
|---|---|---|
| 具体的难目标胜过"尽力而为" | Locke 与 Latham 对约 35 年目标设定研究的回顾 | 第 5 步：给出数字化、听起来不可能的目标，字面要求作为底线 |
| 相信可能 | Dantzig 把两个未解难题当作业做了出来 | 执行时把目标当作可解，不要一上来先列做不到的理由 |
| 看到别人做到 | Bannister 跑进四分钟一英里后，很快有人跟上 | 找先例：总有人达到过类似的标准。在方案里引用它，给目标定锚 |
| 允许失败 | 《The Inner Game of Tennis》；Linux 一开始"只是个爱好" | 难目标没达成、但用真实数字如实报告，是可以接受的结果；悄悄降低目标则不行 |
| 只在窄领域相信自己（米开朗基罗："我是雕塑家"） | | 不要因为某个方法不在显而易见的学科里就拒绝它，广度就是为此存在的 |

## 护栏
- 信念作用于投入和探索，不作用于结论。自信永远代替不了裁判。
- 坚持也有停止条件：至少两种真正不同的思路，各自测量，然后报告具体阻碍。
- 野心永远不能凌驾于关卡、安全和用户明确划定的范围之上。
